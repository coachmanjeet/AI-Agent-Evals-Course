# Multimodal evals — the essential additions

Your course evals are text-only. The moment an agent sees a photo, hears audio,
or produces anything beyond text, you need three new ideas. Everything here is
distilled from production multimodal-eval practice into teachable pieces.

| File | The one idea | Course fit |
|---|---|---|
| `cross-modal-consistency.md` | Check outputs against each other, claim by claim | New capability |
| `ingestion-fidelity.md` | Grade whether the agent actually saw/heard the input right | New capability |
| `eval-contracts.md` | Organize evals as contracts with kappa-gated deployment | Week 6 upgrade |
| `eval-debt-register.md` | Quarterly audit of your eval program's health | Week 6 upgrade |
| `experiment-pre-registration.md` | Lock the decision rule before you see data | Week 6 upgrade |
| `decode-session.md` | A 90-minute ritual for planning evals with a PM | Weeks 1–2 |

Pronto example used throughout: a customer uploads a **photo of a damaged
grocery item** and asks for a refund. The agent must look at the photo, read
the text, and respond consistently.
