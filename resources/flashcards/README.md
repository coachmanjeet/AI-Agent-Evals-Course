# AI Agent Evals Flashcards — Deck README

20 original cards across 5 parts. One agent (Pronto, a grocery-support bot)
runs through every card, so the ideas stay concrete.

**How to use:** read the question, answer out loud, then check. Each card has
one question, a short spoken-English answer, a Pronto example, and a pointer
to the course week and FAQ section.
